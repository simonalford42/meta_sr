\caption{Three scalar regression problems for Base-4 addition (original integer encoding). The observed state set has 8 states, yielding 128 state--input pairs for each transition relation and 8 inputs for the output relation. Entries give exact-recovery counts out of ten search seeds; the bottom row counts seeds in which all three subproblems are recovered together. The last column shows recovered MIPS-evolved expressions from run indices 4, 3, 2, respectively. $h=(h_0,h_1)$ is the integer-encoded hidden state, $a,b$ are the two input digits, primes denote the next state, and $y$ is read from the (new) hidden state. Here $\mathrm{lt}(a,b)=\mathbf{1}[a<b]$, $\mathrm{eq}(a,b)=\mathbf{1}[|a-b|<0.5]$, $\mathrm{zero}(a)=\mathrm{not}(a)=\mathbf{1}[|a|<0.5]$, $\mathrm{mod}(a,b)=a\bmod|b|$, and $\mathrm{xor}(a,b)=(\mathrm{round}(a)+\mathrm{round}(b))\bmod 2$. Expressions are algebraically regrouped, simplified using the observed value sets, and constants rounded to six significant digits; the displayed forms are verified against the complete recorded relations within absolute tolerance $10^{-9}$. Each fit uses at most $10^6$ evaluations and a 500-second timeout. Run 709714 was evolved directly on MIPS.}
