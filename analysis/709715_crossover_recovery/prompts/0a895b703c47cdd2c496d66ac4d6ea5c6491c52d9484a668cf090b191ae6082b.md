```julia
"""
    age_diversity_survival_pareto_shield_gen23_3(pop, options; exclude_indices=Int[]) -> Int

Hybrid age-based survival that generalizes the elite-protection idea from
`age_diversity_survival_hybrid_gen20_2` into a lightweight **Pareto shield**,
while keeping the cheap sampled/global age-pressure mixture from both parents.

Motivation from the trace: pure age-regularized survival (parent 1) and pure
sampled-age survival (parent 2) both let the frontier converge onto
elaborations of a *single* motif (e.g. repeatedly decorating one
`(x0 + sin(x0)) * ...` skeleton) because only the single best-cost individual
was ever protected — every other complexity level was fair game for random
age-death, including the small, structurally distinct scaffolds that
crossover/mutation need to escape a local motif. This operator instead
protects the *entire* cheap Pareto frontier (the best-cost member at each
distinct complexity value), not just the single global best, so multiple
independent building blocks of different sizes survive simultaneously and
remain available as recombination scaffolds — while unprotected (dominated,
redundant) members still turn over under age pressure exactly as before.

Steps:
1. One O(n) pass computes, for every complexity value present in the
   population, the index of its lowest-cost member (`best_at_complexity`).
   The union of these indices is the "shield" — the same handful of slots
   that would appear on a Pareto front plot of cost vs. complexity.
2. With probability `global_prob` (0.2), mimic parent 1: deterministically
   scan the whole population and delete the oldest member that is neither
   excluded nor shielded (guarantees regular, non-random turnover of stale
   dominated material).
3. Otherwise, mimic parent 2: draw `n_sample = clamp(tournament_selection_n,
   2, n)` uniform random slots and delete the oldest one that is neither
   excluded nor shielded (soft age pressure, cheap, allocation-free per draw).
4. Fallback chain guarantees a valid, non-shielded, non-excluded return when
   possible, then relaxes the shield if every legal slot is protected, and
   finally relaxes everything but `exclude_indices` as a last resort.

Assumptions: `birth` is monotonically increasing (smaller = older), `pop.n >=
1`, `exclude_indices` is tiny, and `compute_complexity` is cheap relative to
evaluating a new offspring (a `Dict` is used since complexity values are not
guaranteed to be densely packed or bounded by `maxsize` at all times).
"""
function age_diversity_survival_pareto_shield_gen23_3(
    pop::Population{T,L,N},
    options::AbstractOptions;
    exclude_indices::Vector{Int}=Int[],
)::Int where {T<:DATA_TYPE,L<:LOSS_TYPE,N}
    n = pop.n
    BT = typeof(first(pop.members).birth)

    # ---- Step 1: build the cheap Pareto shield (best cost per complexity). ----
    best_at_complexity = Dict{Int,Int}()
    best_cost_at_complexity = Dict{Int,L}()
    @inbounds for i in 1:n
        c = compute_complexity(pop.members[i], options)
        cost = pop.members[i].cost
        prev = get(best_cost_at_complexity, c, nothing)
        if prev === nothing || cost < prev
            best_cost_at_complexity[c] = cost
            best_at_complexity[c] = i
        end
    end
    # Cheap membership test set: the shielded slot indices.
    shielded = Set{Int}(values(best_at_complexity))

    best_idx = 0
    best_birth = typemax(BT)

    # ---- Steps 2 & 3: mixture of global-oldest and sampled-oldest, respecting the shield. ----
    global_prob = 0.2
    if rand() < global_prob
        # Parent-1 style deterministic scan, skipping excluded and shielded slots.
        @inbounds for i in 1:n
            (i in exclude_indices) && continue
            (i in shielded) && continue
            b = pop.members[i].birth
            if best_idx == 0 || b < best_birth
                best_idx = i
                best_birth = b
            end
        end
    else
        # Parent-2 style sampled scan, skipping excluded and shielded slots.
        n_sample = min(n, max(2, options.tournament_selection_n))
        @inbounds for _ in 1:n_sample
            i = rand(1:n)
            (i in exclude_indices) && continue
            (i in shielded) && continue
            b = pop.members[i].birth
            if best_idx == 0 || b < best_birth
                best_idx = i
                best_birth = b
            end
        end
    end

    # ---- Step 4a: sampling found nothing legal -> deterministic scan, shield still respected. ----
    if best_idx == 0
        @inbounds for i in 1:n
            (i in exclude_indices) && continue
            (i in shielded) && continue
            b = pop.members[i].birth
            if best_idx == 0 || b < best_birth
                best_idx = i
                best_birth = b
            end
        end
    end

    # ---- Step 4b: every legal slot is shielded -> relax the shield, keep exclusion. ----
    if best_idx == 0
        @inbounds for i in 1:n
            (i in exclude_indices) && continue
            b = pop.members[i].birth
            if best_idx == 0 || b < best_birth
                best_idx = i
                best_birth = b
            end
        end
    end

    # Guaranteed non-zero as long as at least one slot is not excluded.
    return best_idx
end
```

## Parent survival operator 2
```julia
"""
Synthesizes the age-regularized replacement strategy (favor removing the
oldest genome) with a quality-aware tie-break so that, among genomes of
similar age, the search preferentially discards the *worse* performer
rather than blindly picking whichever happens to be oldest.

Motivation: pure age-regularized survival (both parents) guarantees healthy
turnover and protects young, still-unevaluated offspring, but it is blind to
fitness — a mediocre-but-old member can be kept alive far too long relative
to peers, or a decent old member can be evicted purely due to birth order
even while a worse, slightly younger member persists. This is visible in
the trace above: complexity keeps climbing with vanishing loss gains,
suggesting bloated members are not being pruned efficiently.

Approach:
1. Rank all eligible (non-excluded) members by age (older -> higher rank)
   and by cost (worse cost -> higher rank).
2. Combine the two ranks into a single score using a tunable weight that
   keeps age as the dominant signal (preserving the original
   age-regularized character and its diversity/turnover guarantees) while
   letting cost break ties and nudge borderline decisions towards removing
   under-performing members.
3. Return the index with the highest combined score, i.e., the oldest and
   (secondarily) worst member, excluding any indices in `exclude_indices`.
"""
function age_and_cost_regularized_survival_gen19_0(
    pop::Population{T,L,N},
    options::AbstractOptions;
    exclude_indices::Vector{Int}=Int[],
)::Int where {T<:DATA_TYPE,L<:LOSS_TYPE,N}
    n = pop.n
    eligible = [i for i in 1:n if !(i in exclude_indices)]
    @assert !isempty(eligible) "No eligible members to replace"

    # Extract raw birth and cost values for eligible members
    births = [pop.members[i].birth for i in eligible]
    costs = [pop.members[i].cost for i in eligible]

    # Rank by age: oldest (smallest birth) gets highest age-rank
    age_order = sortperm(births)  # ascending birth -> first is oldest
    age_rank = similar(age_order, Float64)
    for (r, idx) in enumerate(age_order)
        age_rank[idx] = (length(eligible) - r + 1) / length(eligible)  # oldest -> 1.0
    end

    # Rank by cost: worst (largest cost) gets highest cost-rank
    cost_order = sortperm(costs)  # ascending cost -> last is worst
    cost_rank = similar(cost_order, Float64)
    for (r, idx) in enumerate(cost_order)
        cost_rank[idx] = r / length(eligible)  # worst -> 1.0
    end

    # Combine ranks: age dominates (weight 0.75) but cost breaks ties and
    # nudges the decision toward removing poor performers among similarly-aged peers.
    age_weight = 0.75
    combined_score = age_weight .* age_rank .+ (1 - age_weight) .* cost_rank

    # Pick eligible member with highest combined score (oldest & worst-biased)
    best_local = argmax(combined_score)
    return eligible[best_local]
end
```
