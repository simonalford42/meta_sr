```julia
"""
    age_diversity_survival_hybrid_gen20_2(pop, options; exclude_indices=Int[]) -> Int

Hybrid age-based survival that interpolates between the two parents:

* Parent 1 (`age_regularized_survival`) always deletes the *globally* oldest
  member.  This guarantees a strict, predictable turnover of stale material but
  makes survival fully deterministic: every new offspring is safe simply by
  being young, and whole lineages get flushed in lock-step, which lets the
  population collapse onto a single motif.
* Parent 2 (`age_tournament_survival_gen11_2`) deletes the oldest member of a
  *small random sample*, which softens age pressure and lets some old,
  structurally different lineages persist (good for crossover scaffolds) — but
  it can, by chance, keep genuinely stale material alive for a long time.

Synthesis / core idea: keep the cheap, allocation-free, exclusion-inline
implementation style of parent 2, but make the *strength* of the age pressure a
stochastic mixture of the two parents, and add one cheap safeguard:

1. With probability `global_prob` (0.2) fall back to parent 1's rule exactly:
   scan the whole population and delete the oldest allowed member.  This
   guarantees that, in expectation, the true oldest member is removed regularly,
   so no lineage can hide forever behind sampling luck.
2. Otherwise, draw `n_sample = clamp(options.tournament_selection_n, 2, pop.n)`
   slots uniformly at random (with replacement, no bookkeeping) and delete the
   oldest sampled slot — parent 2's regularized-evolution sampling rule, which
   preserves structural diversity.
3. Elite protection: the single lowest-cost member of the population is never
   deleted while any other legal candidate exists.  Age-only rules can (rarely)
   evict the current best expression before it has been copied into the hall of
   fame / other populations; protecting one slot costs a single O(n) pass and
   removes that failure mode without weakening age turnover in any meaningful
   way (only one of `pop.n` slots is shielded).
4. Fallback chain guarantees a valid return value and that `exclude_indices` is
   never violated: sampled pick → full scan excluding the elite → full scan
   allowing the elite.

Assumptions: `birth` is a monotonically increasing counter (smaller = older),
`pop.n >= 1`, and `exclude_indices` is tiny (so `in` is cheap).
"""
function age_diversity_survival_hybrid_gen20_2(
    pop::Population{T,L,N},
    options::AbstractOptions;
    exclude_indices::Vector{Int}=Int[],
)::Int where {T<:DATA_TYPE,L<:LOSS_TYPE,N}
    n = pop.n
    BT = typeof(first(pop.members).birth)

    # ---- Step 3 (precompute): locate the elite (lowest cost) member. ----
    # Single allocation-free pass; this slot is shielded from deletion unless it
    # is the only legal candidate.
    elite_idx = 1
    elite_cost = pop.members[1].cost
    @inbounds for i in 2:n
        c = pop.members[i].cost
        if c < elite_cost
            elite_cost = c
            elite_idx = i
        end
    end

    best_idx = 0
    best_birth = typemax(BT)

    # ---- Steps 1 & 2: choose between global-oldest (parent 1) and sampled-oldest (parent 2). ----
    global_prob = 0.2
    if rand() < global_prob
        # Parent-1 behaviour: deterministic scan for the globally oldest allowed
        # member (elite still shielded here; relaxed in the final fallback).
        @inbounds for i in 1:n
            (i in exclude_indices) && continue
            i == elite_idx && continue
            b = pop.members[i].birth
            if best_idx == 0 || b < best_birth
                best_idx = i
                best_birth = b
            end
        end
    else
        # Parent-2 behaviour: oldest within a small uniform random sample.
        n_sample = min(n, max(2, options.tournament_selection_n))
        @inbounds for _ in 1:n_sample
            i = rand(1:n)
            # Exclusion + elite protection handled inline (no sentinel array).
            (i in exclude_indices) && continue
            i == elite_idx && continue
            b = pop.members[i].birth
            if best_idx == 0 || b < best_birth
                best_idx = i
                best_birth = b
            end
        end
    end

    # ---- Step 4a: sampling found nothing legal -> deterministic scan (elite still shielded). ----
    if best_idx == 0
        @inbounds for i in 1:n
            (i in exclude_indices) && continue
            i == elite_idx && continue
            b = pop.members[i].birth
            if best_idx == 0 || b < best_birth
                best_idx = i
                best_birth = b
            end
        end
    end

    # ---- Step 4b: truly degenerate case (elite is the only non-excluded slot). ----
    if best_idx == 0
        @inbounds for i in 1:n
            (i in exclude_indices) && continue
            b = pop.members[i].birth
            if best_idx == 0 || b < best_birth
                best_idx = i
                best_birth = b
            end
        end
    end

    # Guaranteed non-zero as long as at least one slot is not excluded.
    return best_idx
end
```

## Parent survival operator 2
```julia
"""
    age_tournament_survival_gen11_2(pop, options; exclude_indices=Int[]) -> Int

Simplified age-regularized survival: instead of always deleting the *globally*
oldest member, this operator draws a small random sample of population slots and
deletes the oldest member **within that sample** (the "regularized evolution"
sampling rule).

Steps:
1. Pick `n_sample = clamp(options.tournament_selection_n, 2, pop.n)` slot indices
   uniformly at random (with replacement — no bookkeeping needed).
2. Skip any sampled slot listed in `exclude_indices`.
3. Return the sampled, non-excluded slot with the smallest `birth` (the oldest).
4. If every draw happened to land on an excluded slot, fall back to a single
   deterministic scan for the oldest allowed member.

What was removed/merged relative to the parent: the parent materialised a full
length-`pop.n` `births` vector (with a `typemax` sentinel written for excluded
slots) and called `argmin_fast` over it. That allocation, the sentinel trick and
the full-population argmin are all gone; exclusion is now handled inline by a
`continue`, and only a handful of members are ever touched.

Why this is still sound: age remains the *only* replacement criterion, so old
material still turns over and the search cannot stagnate on stale members; the
mandatory scan fallback guarantees a valid index is always returned and that
`exclude_indices` is never violated. The softer (sampled) age pressure means a
freshly created, well-performing individual is no longer guaranteed to survive
just by being young, and long-lived members occasionally persist — which
preserves structural diversity. In the traced run the frontier converged onto one
bloated `log(square(x3))/sqrt(x1)` motif and kept decorating it; keeping some
older, structurally different lineages alive gives crossover/mutation alternative
scaffolds to recombine instead of endlessly polishing a single one.
"""
function age_tournament_survival_gen11_2(
    pop::Population{T,L,N},
    options::AbstractOptions;
    exclude_indices::Vector{Int}=Int[],
)::Int where {T<:DATA_TYPE,L<:LOSS_TYPE,N}
    n = pop.n
    BT = typeof(first(pop.members).birth)

    # Small random sample of slots; bounded by the population size.
    n_sample = min(n, max(2, options.tournament_selection_n))

    best_idx = 0
    best_birth = typemax(BT)

    for _ in 1:n_sample
        i = rand(1:n)
        # Exclusion handled inline (replaces the parent's typemax sentinel array).
        (i in exclude_indices) && continue
        b = pop.members[i].birth
        if best_idx == 0 || b < best_birth
            best_idx = i
            best_birth = b
        end
    end

    if best_idx == 0
        # Degenerate case: all draws were excluded. Deterministically take the
        # oldest allowed member so a valid index is always returned.
        for i in 1:n
            (i in exclude_indices) && continue
            b = pop.members[i].birth
            if best_idx == 0 || b < best_birth
                best_idx = i
                best_birth = b
            end
        end
    end

    return best_idx
end
```
