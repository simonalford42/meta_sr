```julia
"""
    pareto_protective_age_regularized_survival_gen22_8(pop, options; exclude_indices=Int[])

Age-regularized survival (replace-the-oldest) refined with a *Pareto-protection*
and *clone-culling* layer.

Core idea
---------
The parent operator always removes the oldest population member. That keeps a
healthy turnover, but it happily deletes a member that is currently the *only*
representative of some region of the accuracy/complexity trade-off curve, while
leaving behind exact duplicates and strictly dominated individuals. This variant
keeps age as the dominant selection pressure, but breaks ties *within the oldest
slice of the population* in favour of removing genuinely redundant material.

Steps
-----
1. Build the candidate list (all indices not in `exclude_indices`) and sort it by
   `birth`, oldest first — age remains the primary driver.
2. Restrict attention to a window containing the oldest ~25% of candidates
   (at least 2). Anything outside the window is considered "too young to die",
   so the operator can never behave much less age-regularized than the parent.
3. Precompute `(complexity, loss)` for every member and classify each windowed
   candidate:
     * rank 0 — broken member (NaN/Inf loss): remove first, it carries no signal;
     * rank 1 — clone: some other member has the same complexity and (to 1e-10
       relative tolerance) the same loss, and is older / lower-indexed, so this
       copy is pure redundancy;
     * rank 2 — Pareto-dominated: another member is at least as simple *and* at
       least as accurate, with strict improvement somewhere;
     * rank 3 — non-dominated (on the population's Pareto front): protected;
     * rank 100 — the current best-cost member: elite, protected unless nothing
       else is available.
4. Return the lowest-rank candidate; because the window is ordered oldest-first,
   ties are resolved by age exactly as in the parent.

Heuristics / safety
-------------------
* If every windowed candidate is non-dominated (rank 3), the returned index is
  simply the oldest candidate, i.e. **identical behaviour to the parent** — the
  operator only deviates when there is something demonstrably redundant to cull.
* `exclude_indices` is honoured by construction (excluded indices never enter the
  candidate list); degenerate populations fall back gracefully.
* Complexity/loss bookkeeping is O(n) plus O(window * n) comparisons, negligible
  next to the loss evaluations performed for each offspring.

Changed vs. parent
------------------
Adds (a) an oldest-slice window instead of a single hard argmin over births,
(b) NaN/Inf-loss purging, (c) clone culling with relative tolerance,
(d) Pareto-front and elite protection, while preserving the parent's fallback.
"""
function pareto_protective_age_regularized_survival_gen22_8(
    pop::Population{T,L,N},
    options::AbstractOptions;
    exclude_indices::Vector{Int}=Int[],
)::Int where {T<:DATA_TYPE,L<:LOSS_TYPE,N}
    n = pop.n
    members = pop.members

    # ---- candidate set: every index not excluded ---------------------------
    candidates = Int[]
    for i in 1:n
        if !(i in exclude_indices)
            push!(candidates, i)
        end
    end
    isempty(candidates) && return 1                # degenerate safety net
    length(candidates) == 1 && return candidates[1]

    # ---- age ordering: oldest first (primary pressure, as in the parent) ---
    sort!(candidates; by = i -> members[i].birth)

    # Only the oldest quarter of the candidates may be reasoned about; this
    # bounds how far we can drift away from pure age-regularized replacement.
    w = max(2, cld(length(candidates), 4))
    w = min(w, length(candidates))

    # ---- precompute complexity, loss and cost for all members --------------
    comps = Vector{Int}(undef, n)
    losses = Vector{Float64}(undef, n)
    elite_idx = 0
    elite_cost = Inf
    for i in 1:n
        comps[i] = compute_complexity(members[i], options)
        l = Float64(members[i].loss)
        losses[i] = isnan(l) ? Inf : l             # treat NaN as worst possible
        c = Float64(members[i].cost)
        c = isnan(c) ? Inf : c
        if c < elite_cost                          # current best-cost member
            elite_cost = c
            elite_idx = i
        end
    end

    best_idx = candidates[1]                       # parent's answer by default
    best_rank = typemax(Int)

    for k in 1:w
        i = candidates[k]
        li = losses[i]
        ci = comps[i]

        rank = 3                                   # assume Pareto-optimal
        if !isfinite(li)
            rank = 0                               # broken: cull immediately
        else
            dominated = false
            duplicate = false
            for j in 1:n
                j == i && continue
                lj = losses[j]
                isfinite(lj) || continue           # broken members dominate nothing
                cj = comps[j]
                if cj == ci && isapprox(li, lj; rtol=1e-10, atol=0.0)
                    # Same complexity and essentially the same loss: whichever
                    # copy is older (index as final tie-break) is the keeper.
                    if (members[j].birth, j) < (members[i].birth, i)
                        duplicate = true
                    end
                elseif cj <= ci && lj <= li && (cj < ci || lj < li)
                    dominated = true
                end
            end
            rank = duplicate ? 1 : (dominated ? 2 : 3)
        end

        # Elitism: never evict the best-cost member while alternatives exist.
        if i == elite_idx
            rank = 100
        end

        if rank < best_rank
            best_rank = rank
            best_idx = i
            best_rank == 0 && break                # cannot do better than this
        end
    end

    return best_idx
end
```

## Parent survival operator 2
```julia
# Custom Survival: age_regularized_survival
# ==========================================
# Default survival strategy: replace the oldest population member, mirroring
# the age-regularized evolution strategy from the original SymbolicRegression.jl.
# Behavior is identical to `default_survival` in CustomSurvival.jl; exposed here
# as a named custom operator so the meta-evolution loop has a concrete parent
# to refine from.

function age_regularized_survival(
    pop::Population{T,L,N},
    options::AbstractOptions;
    exclude_indices::Vector{Int}=Int[],
)::Int where {T<:DATA_TYPE,L<:LOSS_TYPE,N}
    BT = typeof(first(pop.members).birth)
    births = [(i in exclude_indices) ? typemax(BT) : pop.members[i].birth
              for i in 1:(pop.n)]
    return argmin_fast(births)
end
```
