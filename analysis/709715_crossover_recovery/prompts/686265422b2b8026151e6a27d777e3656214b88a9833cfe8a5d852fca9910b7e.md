```julia
"""
    motif_duplication_with_rational_coupling_gen12_gen20_5(tree::N, options, nfeatures::Int, rng::AbstractRNG) where {T,N<:AbstractExpressionNode{T}}

Structural mutation that **reuses evolved structure**: it clones a subexpression *motif*, optionally
re-indexes its variables, and couples the clone back into the tree either as a plain symmetric
accumulation (`target ⊕ motif`) or inside a **self-referential rational template**
(`target / (1 ± motif)`).

# Core Idea (synthesis of both parents)
Both parents exploit the observation that ground-truth laws are built from *repeated functional
forms* applied to different variables (`0.5*m*(vx^2+vy^2)`, `(x1-x2)^2+(y1-y2)^2`, `a*b+c*d`), and
that duplicating a subtree that evolution already discovered is exponentially cheaper than
rediscovering it. Parent 1 contributes the compact, single-traversal feature-shift design; parent 2
contributes size budgeting, motif-quality tiering, targeted feature substitution and operator bias.

This version adds one genuinely new coupling mode motivated by the search trace: the frontier on
`x0/(1 + x0/(x1*x2^2)*(1-cos(x3)))` stalled because the population could only ever *add* structure
(`x0 * (x2 + log(...))`), never wrap an already-good subexpression into a **denominator that contains
a copy of itself**. Such "saturating"/"self-correcting" rational forms are ubiquitous in physics
(relativistic corrections, Compton scattering, Michaelis–Menten, lens/resistor laws, feedback gains)
and are essentially unreachable by point mutations, since they require the same subexpression to
appear both in the numerator and inside `1 + (...)` in the denominator. Duplicating a motif is
exactly the machinery needed, so we reuse it for the rational template.

# Steps
1. Guard: need at least one binary operator.
2. Locate the indices of `+`, `-`, `*`, `/` once (used for biasing and for the rational template).
3. Pick a coupling template up front, because the two templates cost different numbers of extra nodes:
   * plain coupling adds `size(motif) + 1` nodes,
   * rational coupling `target / (c ± motif)` adds `size(motif) + 3` nodes.
   Derive the donor size budget from `options.maxsize` accordingly so the child is admissible.
4. Tiered donor sampling (from parent 2): prefer compound, variable-bearing subtrees that fit the
   budget (those are the meaningful symmetry carriers); fall back to any variable-bearing subtree,
   then to any subtree that fits.
5. Remap the motif's features with one compact traversal helper: cyclic shift by `k` (replicate a
   form across a variable block), targeted substitution of a single feature (pairwise exchanges such
   as `x → y`, which a global shift cannot express), or identity (powers / rational self-couplings).
   If donor and target coincide and identity was drawn, a nonzero shift is sometimes forced to avoid
   trivially simplifiable `u ⊕ u`.
6. Couple: with probability ~0.35 (when `/` and `+`/`-` exist and the budget allows) build the
   rational template `target / (c ± motif)` with `c = 1` (constant optimization refines it);
   otherwise splice `target ⊕ motif` with `⊕` biased toward `+`/`*` and randomized operand order.

# Assumptions / heuristics
- `size(tree) + size(motif) + extra` is the resulting complexity, since the target subtree is
  duplicated in place; the budget check is therefore conservative but cheap.
- `c = 1` is the canonical scale in dimensionless correction factors; PySR's constant optimizer will
  adjust it.
- Rational coupling is the minority mode (35%) so the operator remains primarily a symmetry
  duplicator, not a division-spammer.
"""
function motif_duplication_with_rational_coupling_gen12_gen20_5(
    tree::N,
    options,
    nfeatures::Int,
    rng::AbstractRNG,
) where {T,N<:AbstractExpressionNode{T}}
    # ---------------------------------------------------------------- Step 1: guard
    options.nops[2] == 0 && return tree

    # ---------------------------------------------------------------- Step 2: operator lookup
    binops = options.operators.binops
    nbin = options.nops[2]
    function _op_index(f)
        for i in 1:nbin
            binops[i] === f && return i
        end
        return nothing
    end
    idx_add = _op_index(+)
    idx_sub = _op_index(-)
    idx_mul = _op_index(*)
    idx_div = _op_index(/)

    # ---------------------------------------------------------------- Step 3: template + size budget
    tree_size = count_nodes(tree)
    maxsize = hasproperty(options, :maxsize) ? options.maxsize : typemax(Int)

    # Rational template needs `/`, one of `+`/`-`, and 3 extra nodes (div, den-op, constant)
    rational_ok = (idx_div !== nothing) && (idx_add !== nothing || idx_sub !== nothing)
    use_rational =
        rational_ok && rand(rng) < 0.35 && (maxsize - tree_size - 3) >= 1

    # Donor must fit the remaining complexity budget
    budget = use_rational ? (maxsize - tree_size - 3) : (maxsize - tree_size - 1)
    budget < 1 && return tree

    # ---------------------------------------------------------------- helpers
    # Distinct feature indices in a subtree
    function _collect_features!(acc::Vector{Int}, node)
        if node.degree == 0
            if !node.constant && !(node.feature in acc)
                push!(acc, node.feature)
            end
        else
            for i in 1:(node.degree)
                _collect_features!(acc, get_child(node, i))
            end
        end
        return acc
    end

    # Apply an arbitrary index map to every variable leaf (single compact traversal)
    function _map_features!(node, fmap)
        if node.degree == 0
            if !node.constant
                node.feature = fmap(node.feature)
            end
        else
            for i in 1:(node.degree)
                _map_features!(get_child(node, i), fmap)
            end
        end
        return node
    end

    _fits(t) = count_nodes(t) <= budget
    _has_var(t) = any(n -> n.degree == 0 && !n.constant, t)

    # ---------------------------------------------------------------- Step 4: donor (tiered)
    n_tier1 = count(t -> t.degree > 0 && _fits(t) && _has_var(t), tree)
    n_tier2 = count(t -> _fits(t) && _has_var(t), tree)
    n_tier3 = count(_fits, tree)

    donor = if n_tier1 > 0 && rand(rng) < 0.8
        # Compound, variable-bearing motifs: the interesting symmetry carriers
        rand(rng, NodeSampler(; tree, filter=t -> t.degree > 0 && _fits(t) && _has_var(t)))
    elseif n_tier2 > 0
        rand(rng, NodeSampler(; tree, filter=t -> _fits(t) && _has_var(t)))
    elseif n_tier3 > 0
        rand(rng, NodeSampler(; tree, filter=_fits))
    else
        return tree  # nothing fits the budget
    end
    motif = copy(donor)

    # ---------------------------------------------------------------- target
    target = rand(rng, NodeSampler(; tree))
    self_coupling = target === donor

    # ---------------------------------------------------------------- Step 5: feature remapping
    if nfeatures > 1
        r = rand(rng)
        if r < 0.40
            # (a) cyclic shift: replicate the functional form across a block of variables
            shift = rand(rng, 1:(nfeatures - 1))
            _map_features!(motif, f -> mod1(f + shift, nfeatures))
        elseif r < 0.72
            # (b) targeted substitution: replace exactly one feature of the motif everywhere
            feats = _collect_features!(Int[], motif)
            if !isempty(feats)
                src = feats[rand(rng, 1:length(feats))]
                dst = rand(rng, 1:(nfeatures - 1))
                dst >= src && (dst += 1)  # uniform over destinations != src
                _map_features!(motif, f -> (f == src ? dst : f))
            end
        else
            # (c) identity: powers (u*u), rational self-couplings (u/(1+u)), ratios (u/u')
            # Only force a shift for degenerate *plain* self-couplings; for the rational
            # template `u/(1+u)` the identity map is exactly what we want.
            if self_coupling && !use_rational && rand(rng, Bool)
                shift = rand(rng, 1:(nfeatures - 1))
                _map_features!(motif, f -> mod1(f + shift, nfeatures))
            end
        end
    end

    # ---------------------------------------------------------------- Step 6: coupling
    target_copy = copy(target)

    new_node = if use_rational
        # Self-referential saturation / correction factor: target / (1 ± motif)
        c = constructorof(N)(T; val=one(T))
        den_op = if idx_add !== nothing && idx_sub !== nothing
            rand(rng, Bool) ? idx_add : idx_sub
        elseif idx_add !== nothing
            idx_add
        else
            idx_sub
        end
        den = constructorof(N)(; op=den_op, children=(c, motif))
        constructorof(N)(; op=idx_div, children=(target_copy, den))
    else
        # Plain symmetric coupling, biased toward the canonical accumulators `+` and `*`
        pref = Int[]
        idx_add !== nothing && push!(pref, idx_add)
        idx_mul !== nothing && push!(pref, idx_mul)
        bin_op = if !isempty(pref) && rand(rng) < 0.65
            pref[rand(rng, 1:length(pref))]
        else
            rand(rng, 1:nbin)
        end
        # Randomize operand order to support non-commutative operators
        children = rand(rng, Bool) ? (target_copy, motif) : (motif, target_copy)
        constructorof(N)(; op=bin_op, children=children)
    end

    set_node!(target, new_node)
    return tree
end
```

## Parent mutation operator 2
```julia
"""
    symmetric_motif_duplication_gen4_9(tree::N, options, nfeatures::Int, rng::AbstractRNG) where {T,N<:AbstractExpressionNode{T}}

A structural mutation operator that identifies, replicates, and recombines modular subexpressions
(motifs) with optional feature-space permutations or direct coupling.

# Motivation & Core Idea
Physical and mathematical expressions commonly exhibit symmetries, repeated structural motifs
(e.g., Euclidean distances `(x1 - x2)^2 + (y1 - y2)^2`, coupled harmonic terms `sin(x1) + sin(x2)`,
or rational envelopes `u / (1 + u^2)`), and multilinear interactions. Standard point mutations
require exponentially many lucky mutations to replicate an evolved subexpression across other
variables. This operator extracts an existing subtree, systematically permutes its feature indices
(or keeps them identical for self-interaction), and couples or grafts the transformed motif back
into the expression tree.

# Steps & Heuristics
1. Sample a donor subtree from the existing expression tree.
2. Deep-copy the donor into an independent motif.
3. If features are present and `nfeatures > 1`, apply one of three feature-space transformations:
   - Cyclic feature permutation (e.g., `x_i -> x_{i+k}`), preserving relational sub-structures.
   - Targeted single-feature substitution (`x_a -> x_b`), useful for asymmetric couplings.
   - Identity mapping (no change), enabling polynomial powers (e.g. `u * u`) and rational forms.
4. Integrate the transformed motif into the tree via either:
   - Binary operator coupling: wraps a target node and the motif under a random binary operator.
   - Homologous grafting: replaces a target node in the tree with the evolved motif.
"""
function symmetric_motif_duplication_gen4_9(
    tree::N,
    options,
    nfeatures::Int,
    rng::AbstractRNG,
) where {T,N<:AbstractExpressionNode{T}}
    # Local helper: recursively collect all active feature indices in a subtree
    function _collect_features!(node, feats::Vector{Int})
        if node.degree == 0
            if !node.constant
                push!(feats, node.feature)
            end
        else
            for i in 1:(node.degree)
                _collect_features!(get_child(node, i), feats)
            end
        end
        return feats
    end

    # Local helper: apply a cyclic shift to all feature leaves in a subtree
    function _shift_features!(node, shift::Int, num_features::Int)
        if node.degree == 0
            if !node.constant
                node.feature = mod1(node.feature + shift, num_features)
            end
        else
            for i in 1:(node.degree)
                _shift_features!(get_child(node, i), shift, num_features)
            end
        end
        return node
    end

    # Local helper: substitute occurrences of a specific feature index with another
    function _remap_feature!(node, from_f::Int, to_f::Int)
        if node.degree == 0
            if !node.constant && node.feature == from_f
                node.feature = to_f
            end
        else
            for i in 1:(node.degree)
                _remap_feature!(get_child(node, i), from_f, to_f)
            end
        end
        return node
    end

    # Fallback: if no binary operators are configured, wrap with a unary operator if possible
    if options.nops[2] == 0
        if options.nops[1] > 0
            node = rand(rng, NodeSampler(; tree))
            new_node = constructorof(N)(;
                op=rand(rng, 1:options.nops[1]),
                children=(copy(node),),
            )
            set_node!(node, new_node)
        end
        return tree
    end

    # Step 1: Select a donor subtree motif to duplicate
    donor = rand(rng, NodeSampler(; tree))
    donor_clone = copy(donor)

    # Step 2: Extract active features and apply feature-space symmetry transformation
    feats = _collect_features!(donor_clone, Int[])
    if !isempty(feats) && nfeatures > 1
        strategy_roll = rand(rng)
        if strategy_roll < 0.45
            # Cyclic permutation: shifts all variable indices by a fixed offset
            shift = rand(rng, 1:(nfeatures - 1))
            _shift_features!(donor_clone, shift, nfeatures)
        elseif strategy_roll < 0.70
            # Targeted substitution: pick one variable present in the motif and remap it
            f_old = rand(rng, feats)
            valid_targets = [f for f in 1:nfeatures if f != f_old]
            if !isempty(valid_targets)
                f_new = rand(rng, valid_targets)
                _remap_feature!(donor_clone, f_old, f_new)
            end
        else
            # Identity: keep exact features to foster powers (e.g. u*u) or rational self-coupling
        end
    end

    # Step 3: Integrate the transformed motif back into the expression
    total_nodes = count_nodes(tree)
    # Use grafting if the tree has sufficient depth/size, otherwise couple via binary operator
    if total_nodes > 3 && rand(rng) < 0.35
        # Homologous Grafting: replace a randomly chosen node with the evolved motif
        target = rand(rng, NodeSampler(; tree))
        set_node!(target, donor_clone)
    else
        # Binary Coupling: pair target node with the motif under a binary operator
        target = rand(rng, Bool) ? donor : rand(rng, NodeSampler(; tree))
        target_copy = copy(target)
        bin_op = rand(rng, 1:options.nops[2])

        # Randomize operand ordering for non-commutative operations (subtraction, division)
        children_tuple = rand(rng, Bool) ? (target_copy, donor_clone) : (donor_clone, target_copy)
        new_node = constructorof(N)(;
            op=bin_op,
            children=children_tuple,
        )
        set_node!(target, new_node)
    end

    return tree
end
```
