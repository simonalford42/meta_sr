```julia
"""
    symmetric_motif_duplication_gen9_6(tree::N, options, nfeatures::Int, rng::AbstractRNG) where {T,N<:AbstractExpressionNode{T}}

A streamlined structural mutation operator that duplicates subexpression motifs and couples
them into the expression tree with optional cyclic feature-space shifts.

# Core Idea
Physical laws and mathematical models frequently feature repeated functional forms across different
variables or dimensions (e.g., kinetic energy `0.5*m*(vx^2 + vy^2)` or distances `(x1 - x2)^2 + (y1 - y2)^2`).
This operator extracts an evolved subtree motif, optionally cyclically shifts its feature indices to
replicate functional structures across variables, and couples it with a target node via a binary operator.

# Steps
1. Return early if no binary operators are configured.
2. Sample a donor subtree and deep-copy it into an independent motif.
3. If `nfeatures > 1`, select a cyclic shift `shift ∈ 0:(nfeatures - 1)` and shift all variable leaves
   in the motif. A shift of 0 keeps variables identical for powers/rational self-couplings.
4. Select a target node in the tree and wrap it with the motif under a random binary operator.

# Simplifications from Parent
- Unified three distinct feature transformation paths (cyclic permutation, targeted substitution,
  and identity mapping) into a single cyclic shift offset (`shift ∈ 0:(nfeatures - 1)`). This eliminates
  the need for `_collect_features!`, `_remap_feature!`, and multi-way branch logic.
- Removed homologous grafting heuristics and unary fallback logic in favor of direct, uniform
  binary operator coupling, streamlining code paths while maintaining modular symmetry discovery.
"""
function symmetric_motif_duplication_gen9_6(
    tree::N,
    options,
    nfeatures::Int,
    rng::AbstractRNG,
) where {T,N<:AbstractExpressionNode{T}}
    # Guard: binary coupling requires at least one binary operator
    options.nops[2] == 0 && return tree

    # Helper: cyclically permute feature indices in the motif leaves
    function _shift_features!(node, shift::Int, num_features::Int)
        if node.degree == 0
            if !node.constant
                node.feature = mod1(node.feature + shift, num_features)
            end
        else
            for i in 1:(node.degree)
                _shift_features!(get_child(node, i), shift, num_features)
            end
        end
        return node
    end

    # Step 1: Sample a donor subtree motif and duplicate it
    donor = rand(rng, NodeSampler(; tree))
    motif = copy(donor)

    # Step 2: Apply cyclic feature transformation (shift == 0 preserves features for self-coupling)
    if nfeatures > 1
        shift = rand(rng, 0:(nfeatures - 1))
        if shift > 0
            _shift_features!(motif, shift, nfeatures)
        end
    end

    # Step 3: Couple target node with the transformed motif under a random binary operator
    target = rand(rng, NodeSampler(; tree))
    target_copy = copy(target)
    bin_op = rand(rng, 1:options.nops[2])

    # Randomize operand ordering to support non-commutative operators
    children = rand(rng, Bool) ? (target_copy, motif) : (motif, target_copy)
    new_node = constructorof(N)(;
        op=bin_op,
        children=children,
    )
    set_node!(target, new_node)

    return tree
end
```

## Parent mutation operator 2
```julia
"""
    symmetry_aware_motif_coupling_gen14_8(tree::N, options, nfeatures::Int, rng::AbstractRNG) where {T,N<:AbstractExpressionNode{T}}

A structural mutation operator that reuses an already-evolved subexpression *motif* by cloning it,
re-indexing its variables, and coupling the clone back into the tree with a (usually additive or
multiplicative) binary operator.

# Core Idea
Ground-truth laws are overwhelmingly built from *repeated functional forms* evaluated on different
variables or dimensions: `0.5*m*(vx^2 + vy^2)`, `(x1-x2)^2 + (y1-y2)^2`, `a*b + c*d`, `sin(x)/x`.
Discovering each copy independently through point mutations is exponentially unlikely, so this
operator recycles structure evolution has already found: duplicate a subtree, remap its features,
and attach it to a target site.

# Synthesis of the two parents
* From parent 1 (`symmetric_motif_duplication_gen9_6`): a single, compact feature-remapping traversal
  and a lean control flow — no homologous-grafting heuristics, no unary fallbacks, one coupling path.
* From parent 2 (`..._gen10_1_gen11_9`): a `maxsize`-derived size budget so the offspring is actually
  admissible, tiered donor sampling that prefers compound variable-bearing motifs (avoiding
  degeneration into `insert_random_op`), targeted feature substitution alongside the cyclic shift,
  self-coupling degeneracy avoidance, and a bias toward the canonical accumulators `+` / `*`.
* New in this version:
  - **Root-biased target selection.** Symmetric motifs in real laws almost always accumulate near the
    *top* of an expression (`f(x) + f(y)`, not deep inside a nonlinearity). With probability `0.35`
    the target is the root, otherwise a uniformly sampled node; this makes the common `A + A'` /
    `A * A'` outer structures reachable in one step.
  - **Adaptive remap-mode weights.** The remap mode is chosen conditioned on the motif itself: if the
    motif carries no variables (constant-only) only the identity map is meaningful; if it carries a
    single feature, targeted substitution and cyclic shift coincide, so the cheaper shift is favored;
    with multiple features targeted substitution is up-weighted, since only it can express pairwise
    exchanges like `x1 → x2` inside `(x1 - x2)`.
  - **Substitution can introduce an unused feature**, which lets the mutation import variables that
    do not yet appear anywhere in the tree (useful early in a run).

# Steps
1. Bail out if there is no binary operator or no size headroom (`maxsize - size(tree) - 1 < 1`).
2. Sample a donor subtree that fits the budget, with tiered preference:
   compound & variable-bearing → variable-bearing → anything that fits.
3. Deep-copy it into an independent motif.
4. Pick the target: the root with probability 0.35, else a uniformly random node.
5. Remap the motif's feature indices via cyclic shift, targeted substitution, or identity
   (forcing a nonzero shift when donor === target and identity was drawn, to avoid trivial `u ⊕ u`).
6. Wrap the target with `motif ⊕ copy(target)` under a binary operator biased toward `+`/`*`,
   with randomized operand order for non-commutative operators.

# Assumptions
* Feature indices are `1:nfeatures`, so `mod1` shifts are always valid.
* Duplication grows the tree by exactly `size(motif) + 1` nodes, which is what the budget enforces.
"""
function symmetry_aware_motif_coupling_gen14_8(
    tree::N,
    options,
    nfeatures::Int,
    rng::AbstractRNG,
) where {T,N<:AbstractExpressionNode{T}}
    # Guard: coupling a duplicated motif requires at least one binary operator
    options.nops[2] == 0 && return tree

    # ------------------------------------------------------------------ size budget
    tree_size = count_nodes(tree)
    maxsize = hasproperty(options, :maxsize) ? options.maxsize : typemax(Int)
    # Result size == tree_size + size(motif) + 1 (target subtree is duplicated in place)
    budget = maxsize - tree_size - 1
    budget < 1 && return tree

    # ------------------------------------------------------------------ helpers
    # Apply an arbitrary index map to every variable leaf of a subtree
    function _map_features!(node, fmap)
        if node.degree == 0
            if !node.constant
                node.feature = fmap(node.feature)
            end
        else
            for i in 1:(node.degree)
                _map_features!(get_child(node, i), fmap)
            end
        end
        return node
    end

    # Distinct feature indices appearing in a subtree
    function _collect_features(node)
        acc = Int[]
        function _walk(n)
            if n.degree == 0
                if !n.constant && !(n.feature in acc)
                    push!(acc, n.feature)
                end
            else
                for i in 1:(n.degree)
                    _walk(get_child(n, i))
                end
            end
            return nothing
        end
        _walk(node)
        return acc
    end

    _fits(t) = count_nodes(t) <= budget
    _has_var(t) = any(n -> n.degree == 0 && !n.constant, t)

    # ------------------------------------------------------------------ Step 1: donor
    # Tier 1: compound, variable-bearing motifs — the genuine symmetry carriers
    _tier1(t) = t.degree > 0 && _fits(t) && _has_var(t)
    _tier2(t) = _fits(t) && _has_var(t)

    donor = if count(_tier1, tree) > 0 && rand(rng) < 0.8
        rand(rng, NodeSampler(; tree, filter=_tier1))
    elseif count(_tier2, tree) > 0
        rand(rng, NodeSampler(; tree, filter=_tier2))
    elseif count(_fits, tree) > 0
        rand(rng, NodeSampler(; tree, filter=_fits))
    else
        return tree  # nothing fits within the complexity budget
    end

    motif = copy(donor)

    # ------------------------------------------------------------------ Step 2: target
    # Root-biased: symmetric accumulations (`f(x) + f(y)`) live near the top of real laws.
    target = if rand(rng) < 0.35
        tree
    else
        rand(rng, NodeSampler(; tree))
    end
    self_coupling = target === donor

    # ------------------------------------------------------------------ Step 3: remap features
    if nfeatures > 1
        feats = _collect_features(motif)
        nf = length(feats)

        if nf == 0
            # Constant-only motif: no remapping is meaningful (identity map).
            nothing
        else
            # Adaptive mode weights: multi-feature motifs benefit most from targeted swaps
            # (e.g. `x1 - x2` → `y1 - y2` needs per-feature substitution, not a global shift).
            p_shift = nf == 1 ? 0.60 : 0.35
            p_subst = nf == 1 ? 0.15 : 0.45
            r = rand(rng)

            if r < p_shift
                # (a) cyclic shift: replicate the whole functional form on the next variable block
                shift = rand(rng, 1:(nfeatures - 1))
                _map_features!(motif, f -> mod1(f + shift, nfeatures))
            elseif r < p_shift + p_subst
                # (b) targeted substitution: replace exactly one feature of the motif everywhere,
                # possibly importing a feature not yet present anywhere in the tree.
                src = feats[rand(rng, 1:nf)]
                dst = rand(rng, 1:(nfeatures - 1))
                dst >= src && (dst += 1)  # uniform over destinations != src
                _map_features!(motif, f -> (f == src ? dst : f))
            else
                # (c) identity: enables powers (`u*u`) and rational self-couplings (`u/u'`).
                # If donor and target coincide, half the time force a shift so we do not
                # produce the trivially simplifiable `u ⊕ u`.
                if self_coupling && rand(rng, Bool)
                    shift = rand(rng, 1:(nfeatures - 1))
                    _map_features!(motif, f -> mod1(f + shift, nfeatures))
                end
            end
        end
    end

    # ------------------------------------------------------------------ Step 4: couple
    # Bias toward `+` and `*`, the canonical symmetric accumulators of physical laws.
    binops = options.operators.binops
    pref = Int[]
    for i in 1:(options.nops[2])
        op = binops[i]
        (op === (+) || op === (*)) && push!(pref, i)
    end
    bin_op = if !isempty(pref) && rand(rng) < 0.7
        pref[rand(rng, 1:length(pref))]
    else
        rand(rng, 1:(options.nops[2]))
    end

    target_copy = copy(target)
    # Randomize operand ordering so non-commutative operators explore both arrangements
    children = rand(rng, Bool) ? (target_copy, motif) : (motif, target_copy)
    new_node = constructorof(N)(; op=bin_op, children=children)
    set_node!(target, new_node)

    return tree
end
```
