\section*{Runs and three match criteria}

Run \textbf{313196} (``top-1'') evolved on \texttt{z\_rebound} and was evaluated
on five other worlds with five seeds each.  Run \textbf{313195} (``top-2'')
evolved on \texttt{z\_rebound} and \texttt{h\_sag} and was evaluated on four
other worlds with five seeds each.  Every criterion searches the complete saved
Pareto frontier.

\begin{itemize}
  \item \textbf{NRMSE match:} some row has held-out $\nrmse\le10^{-6}$.
  \item \textbf{Project symbolic match:} the current
  \path{evaluation.check_pysr_symbolic_match} logic, including the $R^2>0.5$
  guard, three-decimal float rounding, and constant-difference/ratio rules.
  \item \textbf{Manual match:} after undoing target-RMS scaling and expanding in
  physical units, some row contains every required current-balance monomial, no
  material extra monomial, and clearly close fitted coefficients.  Tiny floating
  artifacts are allowed; missing $I_{\rm ext}$ or leak-$V$ is not.
\end{itemize}

Two inexpensive GPT-5.6 Luna reviewers each inspected one complete evolution run
(25 and 20 frontiers).  A third Luna reviewer audited all 45 decisions.  The
primary and audit decisions agreed on 44/45 cases before adjudication.  Selected
rows were programmatically checked against the correct source run after an initial
cross-run cache contamination was detected and corrected.

\textbf{Symbolic false positives.}  Both are \texttt{d\_type}, seed 10003:
run 313196 has NRMSE $7.94\times10^{-4}$ and run 313195 has
$8.10\times10^{-4}$.  Manual expansion finds a missing or materially inaccurate
leak/intercept contribution.  Coarse rounding followed by the checker's
constant-difference rule erases the discrepancy.

\textbf{Symbolic false negatives.}  Four manually valid frontiers fail the
project checker: run 313196 \texttt{ca\_rebound} seed 10000, plus run 313195
\texttt{ca\_rebound} seed 10000, \texttt{d\_type} seed 10004, and
\texttt{textbook\_M} seed 10001.  The latter three have NRMSE between
$2.5\times10^{-10}$ and $3.1\times10^{-7}$; factorization-sensitive rounding,
not a scientific mismatch, causes their symbolic failures.

\section*{The one reviewer disagreement}

The top-1 primary reviewer accepted \texttt{ca\_rebound}, seed 10000; the audit
reviewer rejected it.  Canonical expansion gives complete ground-truth support,
no extra monomials, and NRMSE $7.376\times10^{-6}$.  Representative physical
coefficients are
\[
I_{\rm ext}:\ 0.999908\ (1),\qquad
V:\ -0.297741\ (-0.3),\qquad
V\phi_T:\ -3.200709\ (-3.2),\qquad
\phi_T:\ 384.027\ (384),
\]
where parentheses contain ground truth.  The largest relative discrepancy among
required coefficients is about $0.8\%$ (the leak-$V$ coefficient), so the final
manual label is \textbf{accept}.  This medium-confidence adjudication is retained
explicitly in the machine-readable record.

\section*{Interpretation}

The $10^{-6}$ NRMSE rule is conservative but clean in this sample: every numerical
recovery survives manual inspection.  The project symbolic checker increases
coverage, but target scaling and representation-dependent rounding create both
false positives and false negatives.  Manual inspection yields the broadest count
(35/45) under the stated physical-law rubric, but it is a judgment-based measure,
not a replacement for numerical reporting.

The most transparent summary is therefore to retain all three columns.  For an
automated future substitute for the manual column, compare canonical expanded
polynomials in physical units using scale-aware coefficient tolerances, while
requiring every ground-truth variable term to remain present.
